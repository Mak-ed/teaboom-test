# Teaboom — карточка товара

Учебный проект по вёрстке страницы товара для интернет-магазина чая Teaboom.

## Ссылка

GitHub Pages: https://mak-ed.github.io/teaboom-test/

## Реализовано

- Адаптивная вёрстка для экранов компьютеров, планшетов и мобильных устройств.
- Карточка товара с выбором фасовки.
- Динамическое обновление цены и артикула при выборе фасовки.
- Отображение текущей и старой цены.
- Увеличение изображения товара в модальном окне.
- Hover-эффекты и состояния интерактивных элементов.

## Технологии

- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (ES6+)

## Запуск проекта

Проект не требует установки зависимостей или сборки. Открой `index.html` в браузере либо запусти проект через локальный сервер.

## Структура проекта

- `index.html` — разметка страницы.
- `styles.css` — стили и адаптивная вёрстка.
- `script.js` — интерактивность страницы.
